# Changelog

## 0.2.0

- Browse by topic when the search line is empty (Files, Network, Git, Packages, Theme, …)
- “Did you mean” suggestions when a query has no exact matches
- Live Omarchy catalog from `omarchy commands --json` (merged on each open)
- Intent tags and query synonyms (e.g. mute mic, folder ↔ directory)
- Auto flags from Omarchy args; related links within Omarchy groups
- Curated Linux/Arch flags and related links for common commands
- `node sync-omarchy.js` to refresh the shipped Omarchy snapshot

## 0.1.0

- Keyboard overlay: search, source pills, result list, detail pane
- Copy examples, cycle examples, open man pages
- Frecency ranking and remembered source filters
- Shipped Linux / Arch / Omarchy library
